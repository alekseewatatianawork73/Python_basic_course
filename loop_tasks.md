## Задача 7. Билеты на аттракцион
В кассе продаются билеты с номерами от **_A_** до **_B_** включительно. Билет считается призовым, если его номер делится на 5, но не делится на 10.

При запуске программы вводятся целые числа **_A_** и **_B_** - номера первого и последнего билета, где _1 ≤ a ≤ b_. Посчитайте количество призовых билетов.

**Примечание:** для номеров от 10-го до 30-го призовыми будут билеты № 15 и № 25. Ответ: 2.

**Пример 1:**

Входные данные:
```
10 30
```
Выходные данные:
```
2
```


**Пример 2:**

Входные данные:
```
1 50
```
Выходные данные:
```
5
```


**Пример 3:**

Входные данные:
```
5 25
```
Выходные данные:
```
3
```

# While - задачи на ввод значений.
------------------------------------------------------------------------------------------------------------------------------------------------------------------

## Задача 1. Вход в систему
Для входа в систему пользователю необходимо ввести пароль. Программа запрашивает пароль до тех пор, пока пользователь не введёт верный. После ввода верного пароля появляется сообщение о том, что доступ разрешён.

При запуске программы в первой строке вводится верный пароль. В следующих строках запрашивается пароль от пользователя — после каждого ввода необходимо выводить сообщение, является ли пароль верным. Как только пользователь введёт верный пароль, нужно вывести «**_Доступ разрешён_**» и завершить программу (см. примеры).

**Примечание.** Обратите внимание, что вывод сообщений происходит _**после каждого введённого значения пароля**_, а не в конце программы. В примере в выходных данных ввод значений обозначен как многоточие (...).

**Пример 1:**

Входные данные:
```
mypass
123
python
pass
mypass
```
Выходные данные:
```
Неверный пароль
...
Неверный пароль
...
Неверный пароль
...
Доступ разрешён
```


**Пример 2:**

Входные данные:
```
qwerty
qwerty
```
Выходные данные:
```
Доступ разрешён
```


**Пример 3:**

Входные данные:
```
abcde
pass
abc
py123
py987
00000
abcde
```
Выходные данные:
```
Неверный пароль
...
Неверный пароль
...
Неверный пароль
...
Неверный пароль
...
Неверный пароль
...
Доступ разрешён
```
